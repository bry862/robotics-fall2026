# Final reflection

Respond to any or all of these prompts:

1. What did this activity make you think about regarding your own interests in robotics, computing, engineering, or related work?
2. How did this activity affect your motivation to do similar kinds of work in the future?
3. What value do you see in connecting technical or computing work with human, ethical, or societal considerations?
4. What stood out to you about the activity, and why?
5. Is there anything else you would like to share about your experience with the activity?

## Response

Doing this lab made me brainstorm some personal project ideas that I could work on. It gave me an idea of how robotics software of robotics works on a surface level. This is something that we often do not think about, as we mainly think about the hardware. Like "An arm that does x", or "a sensor that looks out for y", but we don't think about how that arm will decide how it will move. Or how the data from the sensor will be handled. So because of this, this lab motivated me to want to do more robotics work. The activities we have done in class have also motivated me to want to do more robotics work. For example, watching the video where the blind lady was testing an app made me realise that we could be doing so much more for people with disabilities using technology. And that is where I see most of the value in robotics: aiding humanity. We can use robotics either to do things we cannot do, like fly. But we can also use robotics to help those who cannot do things that we as a human species can already do, like walk. We can take our imagination and think; we can use technology and robotics to help people see, or help a heart pump blood better, in some future where robotics is more advanced. For now, we can help people do simpler things like navigate a building or use a phone (which is what was being done in the video we saw in class).
